# Project artwork

README graphics live here alongside the project documentation.

| Asset | Use |
| --- | --- |
| [`ipi-nft.svg`](ipi-nft.svg) | Self-contained, editable README banner in the secure-element icon's navy and blue palette, with the original icon on the right. |
| [`secure-element.png`](secure-element.png) | IPI chip icon for the upcoming secure-element integration. |
| [`secure-element-dog.png`](secure-element-dog.png) | Security guardian artwork for the “Infinite security” section. |

Reference these assets with relative paths. Keep source PNGs at their original quality and use display widths in the README to size them.

The banner embeds the original `secure-element.png` bytes so the same icon displays when the SVG is used as a standalone image. Refresh that embedded image whenever the source icon changes.
